# null ballots; Table II (p. 20) seats, lists and candidates; Table III (p. 21) candidates by party (skipped); Table IV

# Table V (p. 23) senators elected by party; Table VI (p. 24) a 1929/1932 comparison (skipped).
# No table prints registered electors, so the turnout tables hold only cast and invalid (population is skipped).
# The volume has three kinds of constituency: A, elected by the people (1-5 proportional system, 6-11 majority system);
# B, eight professional organizations (numbered 1-8 again in the volume, coded B1-B8 here); and C, the 10 senators
# elected by the Chamber and the Senate. Party votes (Table IV) exist only for A: B and C elect candidates who are not
# counted by party (Table V puts all their 28 seats under Ακαθόριστοι), so they appear only in turnout and seats.
# The printed nesting (subtotals for the two systems, a total for A, a subtotal for B, then a general total that adds
# A + B + C) does not fit the checker's '=' and '==' within one block, so A and B/C are separate blocks and the general
# totals are kept as `# total:` comment lines, checked by hand against the rows. The B/C blocks come before the A blocks
# because the checker keys subtotals by their order in a block, and the A subtotals must be the ones it cross-checks.
